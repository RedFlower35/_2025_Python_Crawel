## 🔧 技術細節摘要

### 前一交易日計算邏輯

```python
# 在 stock_crawler.py 中實現
today = datetime.now()
for i in range(1, 4):  # 最多往前推 3 天
    prev_day = today - timedelta(days=i)
    # 檢查是否為工作日 (Monday-Friday)
    if prev_day.weekday() < 5:  # 0-4 = Mon-Fri, 5-6 = Sat-Sun
        break
# prev_day 即為前一交易日
```

## 📞 常見問題

### Q: 為什麼有些股票顯示「(前一交易日)」?
**A**: 正常現象，表示當日市場未開放或無交易紀錄，資訊會在營業日更新為當日。

### Q: 搜尋為什麼找不到股票?
**A**: 
- 確認股票代碼正確 (4 位數字)
- 試試股票名稱而非代碼
- 查看 `taiwan_stocks.py` 確認股票是否在列表

### Q: 應用卡住怎麼辦?
**A**:
- 檢查網路連線
