```python

```

**工作流程：**
1. 優先嘗試取得當日(today)資料
2. 若當日無資料或爬蟲失敗，自動嘗試前一交易日

4. 返回資料時標記資料類型（today / previous_trading_day）

#### 資料驗證

## 📊 技術細節

### 1. 前一交易日計算邏輯

```python
# 計算前一交易日（往前推一天，跳過週末）
today = datetime.now()
for i in range(1, 4):  # 最多往前推 3 天
    prev_day = today - timedelta(days=i)
    # 跳過週末（5=Saturday, 6=Sunday）
    if prev_day.weekday() < 5:
        break
```

### 2. 資料有效性檢查

```python
# 檢查資料是否有實際的即時價格
if result.success and result.extracted_content:
    data = result.extracted_content
    if isinstance(data, dict) and data.get("即時價格"):
        # 資料有效
    else:
        # 資料無效，嘗試前一交易日
```

### 3. 返回資料格式

```python
{
    "stock_code": "2330",
    "success": True,
    "data": {
        "即時價格": "993.00",
        "漲跌": "+15.00",
        "漲跌百分比": "+1.53%",
        ...
    },
    "date_type": "today" | "previous_trading_day",  # 資料類型
    "trading_date": "2025-12-19"  # 若是前一交易日
}
```

### 常見問題

**Q: 為什麼有些股票顯示前一交易日資料？**  
A: 可能原因：
- 當天市場未開放（假日、國定假日）
- 當天股票未開盤
- 資料網站暫時無法取得當日資料

**Q: 搜尋為什麼找不到股票？**  
A: 
- 確認輸入正確的股票代碼或名稱
- 台灣股票代碼通常是 4 位數字
- ETF 代碼通常是 4 位數字加字母（如 0050）

**Q: 可以添加自己的股票嗎？**  
A: 可以。編輯 `taiwan_stocks.py` 的相應字典並重啟應用
