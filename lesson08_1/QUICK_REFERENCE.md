## 常見問題

### Q: 為什麼有些股票顯示「(前一交易日)」?
**A**: 正常現象，表示：
- 當日市場未開放（假日）
- 或當日無交易紀錄
- 資訊仍然有效，會在營業日更新為當日

### Q: 搜尋找不到某支股票?
**A**: 檢查清單：
- 股票代碼是否正確 (4位數字)
- 查看 `taiwan_stocks.py` 確認名稱拼法
- 試試代碼或名稱分開搜尋

### Q: 應用卡住了?
**A**: 檢查事項：
- 網路連線是否正常
- 查看控制台是否有錯誤訊息
- 點「🔄 手動更新」重試

### Q: 如何添加更多股票?
**A**: 編輯 `taiwan_stocks.py`:
```python
TWSE_STOCKS = {
    "2330": "台積電",
    "9999": "我的股票",  # ← 添加這行
}
```
